📊 Desafio Power BI: Construção e Customização de Relatórios Visuais
📌 Sobre o Projeto
Este repositório contém a solução do primeiro desafio prático da trilha Power BI Analyst da Digital Innovation One (DIO).

O objetivo do desafio foi criar e estruturar um relatório interativo de vendas no Power BI a partir de uma base de dados sample, aplicando conceitos de visualização de dados, layout, organização de páginas e publicação.

📈 Estrutura do Relatório
O relatório foi dividido em três páginas principais:

Páginas 1 e 2 (Réplica do Conteúdo):

Construídas com base na aula prática, replicando os visuais e métricas apresentados pelo expert.

Página 3 (Desafio Autônomo - Análise Visual Customizada):

Visual de Mapa 1: Soma de Vendas (Sales) e Unidades Vendidas por País.

Visual de Mapa 2: Soma de Lucro (Profit) por País.

Visual de Pizza: Distribuição do Lucro por Segmento de Mercado.

🛠️ Boas Práticas Aplicadas
Clareza nos Títulos: Todos os visuais foram renomeados para torná-los intuitivos e adequados ao contexto de negócio.

Dicas de Ferramentas (Tooltips): Configuração refinada de campos de detalhamento para enriquecer a navegação sem poluir a tela.

Disposição e Layout: Organização dos elementos gráficos garantindo leitura fluida e usabilidade.

Publicação e Compartilhamento: Relatório publicado no serviço Power BI e exportado para apresentação/suplemento no PowerPoint.
